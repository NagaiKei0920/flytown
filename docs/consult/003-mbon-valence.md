# 003 MBON の接近/忌避の割り当て（学習試験の読み出し）

## 問題
学習試験 13 の「接近駆動」を、MBON の発火率を価値の向きで重み付けした和にした。価値の向きは注釈に無いので、神経伝達物質で決めた。
コリン作動性 +1（接近促進）、グルタミン酸作動性 -1（忌避促進）、GABA ほか 0（Aso+ 2014、Owald+ 2015 の一般則を記憶から当てたもの。文献の再確認はしていない）。
最初に逆（Glu = +1）で走らせたら効果が負になり、符号を文献の記憶に合わせて直した。結果を見てからの修正なので、符号の根拠が弱いことは報告に明記する。

## 既定案
上の割り当てで進める。

## 代案
MBON タイプごとの区画（γ5β'2a など）を Aso+ 2014 の表から引いて割り当てる。注釈の cell_type から区画への対応表が要る（M4 で行動への接続を作るときに必要）。
