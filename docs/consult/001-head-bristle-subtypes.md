# 001 頭部剛毛（head bristle）の細胞タイプ分割

## 問題
M0 の入力定義「cell_sub_class = head bristle（305）」は、口吻・味覚毛などを含む。
タイプ別に 1 種だけ刺激した応答（調整前、z 単位）:

| タイプ | 数 | DNg12（身繕い） | 摂食 MN |
|---|---|---|---|
| BM_vOcci_vPoOr | 52 | +3.5 | 0 |
| BM_dOcci | 6 | +1.5 | 0 |
| BM_Hau | 10 | +0.4 | +7.8 |
| BM_Taste | 72 | 0 | +1.4 |
| BM_Ant / BM_Vib / BM_MaPa ほか | 計 約 150 | 約 0 | 0 |

全部まとめて入れると摂食 MN が強く上がり、身繕い（項目 11）は不合格になる。

## 既定案（今回の実装）
M0 の定義のまま（305 細胞全部を `bristle` チャネルにする）。項目 11 は不合格のまま報告する。

## 代案
`bristle` を後頭部系（BM_vOcci_vPoOr、BM_dOcci、BM_Oc、BM_InOc、BM_InOm）に限る。粉じんが付く場所の想定に合う。
BM_Taste・BM_Hau は糖/苦味とは別に「口吻への接触」チャネルとして残す。
選別基準が結果を見てからの後付けになるため、M0 の仕様変更として Opus の判断を仰ぐ。
