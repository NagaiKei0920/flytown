## 作ったもの
- お題モード（`web/src/sim/modes.ts`、UI は `ui.ts`）。ツールバーの「お題」で小さなカード（自由 / パン屋へ / 殺虫器 / 車道を渡る、対象のハエ人、最高記録、開始）。実行中は上中央に残り時間と数値、終了で結果カード（得点 1 つ、式、最高記録、もう一度）。最高記録は localStorage（try/catch）。
  - パン屋へ: 開始時にハエ人を固定の位置（-22, -18、東向き）へ置き直し、脳を reset。パン屋の戸口（poi shop-bakery）から 3 m 以内で達成。得点 = 時間 x (注射回数 + 1)。3 分で時間切れ（記録なし）。
  - 殺虫器: 殺虫器が無ければ既定位置に戻し、その 12 m 手前から少しそれた向きで開始。3 分後に終了。得点 = 感電回数 x 1000 + 4 m 以内にいた秒数（同数なら近くにいた時間が短い方が上）。
  - 車道を渡る: 中央の道路（x = 0）の西歩道（-6.5, -30、北向き）から開始、x >= 4.5 で達成。得点 = 時間 x (事故 + 1)。3 分で時間切れ。
  - 開始時の置き直し・脳 reset 以外はハエ人の動きに触れない（判定と採点のみ）。`FlyPerson.teleport`、`Sim.homes` を追加。
- 言語切替（`ui/i18n.ts`）: 日本語 / English の辞書 1 つ。設定タブの切替で即時反映、localStorage に保存。既定は日本語。街の看板の文字（3D テクスチャ）は対象外。
- 行動計測 `npm run check:behavior`（`web/scripts/check-behavior.mjs`）。結果は `docs/reports/m5_behavior.md`。
- README.md（日本語 + English）、LICENSE（MIT、Kei Nagai、2026）、`.github/workflows/pages.yml`（Node 24、`npm ci` + `npm run build`、dist に circuit・models があることを確認、deploy-pages）。

### 読み方（解釈。計測後に気づいたこと。調整はしていない）
- 前進指令は静止時に約 0.5（V0）で、ハエ人は匂いが無くても約 0.85 m/s で直進する。60 s で 40 m 以上動くので、最初の向きで「2 m 以内に入るか」がほぼ決まる。対照・バナナ・カビで割合・最短距離・到達時間がほとんど同じなのはこのため。匂いによる旋回が軌跡に効いていない（刺激応答表でも旋回の左右差は酢と暑さだけ合格）。
- 学習で動いたのは好みの探り値（MBON の接近駆動）だけで、歩行の向きには結びついていない。読み出しが MBON を直接使っていないため。SPEC の学習基準（+20 点）は、この指標では満たせていない。
- 逃避は DNp01 の出力が強く出るため確実（逃避までの中央値 0.2 s）。ただし対照でも 35% が羽ばたく（街の壁・看板への looming 等）。
- 別エージェントが回路・読み出しを更新した場合は、`npm run check:behavior` を回し直すこと。この結果の回路は sha256 先頭 12 桁 `dc58423c3a0f`。

## 脳パネルの「匂いの好み」の変更（レビュー指摘）
- 問題: 起動直後から酢・発酵臭 -0.98、仲間のにおい +0.66 などの絶対値が出ていた。値は未検証の MBON 価値割り当て（consult/003）由来で、実際のハエは酢に誘引されるため誤解を招く。
- 変更: パネルの見出しを「注射で変わった好み」（en: Preference change from injections）にし、暖機直後（注射前）のそのハエ人自身の探り値を基準として、変化だけを表示する。変化 = tanh((匂いの接近駆動 - 無刺激の接近駆動 - 基準の同じ差) / 1.0)、範囲 -1〜+1。起動直後は全匂い 0。0 は色なし・幅 0 で表示する。以前の「最後の注射からの変化」列は廃止。
- 生の探り値は折りたたみのセンサ欄（「好み(生)」の行）にだけ残した。`ConnectomeDebug.preference` は生、`preferenceChange` が新しい値。基準は Worker 起動時の暖機直後に `BrainBatch.captureBaseline()` で取り、`reset` 後は次に完了した探りを新しい基準にする。
- 検証（`node scripts/check-brain.mjs`）: 基準直後の変化は 5 匂いすべて 0.000。fruit + ご褒美 3 回後の変化は vinegar +0.096、geosmin -0.000、co2 -0.056、cva +0.023、fruit +0.053。学習していない体は全 0.000。注意: 対提示した fruit より vinegar の変化が大きい（接近駆動の差が tanh で飽和する生の値では見えなかった）。匂い間の汎化を含み、対提示の匂いだけが動く指標にはなっていない。
