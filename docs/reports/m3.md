# M3 報告: 3D の街・体・センサ

## 作ったもの
- 街（約 300 m x 300 m、道路 5x5、ブロック 4x4、シード固定）。道路・車線・横断歩道・停止線・歩道・街灯・木・ベンチはコード生成。一般のビルは Kenney City Kit Commercial（CC0）。
- 店 7 種（パン屋・喫茶店・焼き鳥屋・果物屋・コンビニ・冷凍倉庫・かき氷屋）は看板・日よけ・屋根飾り付きの手続き生成。ほかにゴミ捨て場、噴水広場、工事現場（クレーン・柱・フェンス）、路地（自転車・室外機・看板）。焼き鳥屋の煙は粒子。
- 車 15 台（Kenney Car Kit、CC0）: 左側通行、交差点は 1 台ずつ通過、確率 30% で一時停止、前の車と横断中の歩行者には止まる。ハエ人には止まらない。
- NPC 20 人（Kenney Blocky Characters、CC0）: 歩道の角をつなぐグラフ上を歩き、車がいなければ横断歩道を渡る。
- ハエ人 4 人: Kenney Blocky Characters の体を BodyCommand だけでコード駆動。頭は差し替え（六角ファセットの赤い複眼、単眼、触角と剛毛、伸びる口吻）。背中に虹色の羽（薄膜干渉をシェーダで再現、残像 3 枚で羽ばたきのぼかし）。
- 歩容: 三脚 A = 左脚、三脚 B = 右脚（逆位相）。周波数 = 速度 / 歩幅、振幅は速度で増える。後退は位相逆回転（ムーンウォーク）。腕は脚と逆位相。
- 羽ばたき: 高さ 12〜40 cm、連続 3 秒で強制着地、羽ばたきを一度離すまで再開不可。身繕い: 手をこする ⇄ 頭をなでるを時間でゆっくり切替。摂食: 前かがみ + 口吻が伸びる。触角は場の左右差から傾く（見た目のみ）。
- 物理: 壁・小物は円と箱の押し出し。車に当たると吹き飛び、寝姿勢で 5 秒、起き上がって 2 秒は無敵。事故数をカウント。
- センサ（`sim/sensors.ts` に型、`sim/sensing.ts` に計算）: 左右各 12 本のレイ（距離・接近速度・looming・種類）、障害物の多さ（前・左・右）、明るさ左右（日向/日陰/店の照明）、触角位置の場（`Field` インターフェース、`StubField` は 0）。デバッグ: 設定タブでレイを 3D 表示、脳タブに数値。
- 脳の境界（`brain/types.ts`）: `BodyCommand`、`BrainAgent`。`ManualBrain`（DEV、WASD/Space/G/F）のみ。自動の脳は無し。脳が無いハエ人は指令 0。
- カメラ: 俯瞰の周回、ハエ人をクリックまたはチップで追従、Tab で切替、Esc / 空地のダブルクリックで解除、V または「複眼」で複眼視点（FOV 115 度 + 六角ファセットの後処理）。
- UI: 下にツールバー（注射器・置く・時間 0x/1x/4x・複眼）、右に脳パネル（仮）と設定タブ。注射器と置くは未実装の通知のみ。
- 性能ログ: 5 秒ごとに `[flytown:perf] fps=... avg_ms=... p95_ms=... draws=... tris=...` をコンソールへ。`window.__flytown` に sim / perf / cam などを公開。

## ファイル
- `web/src/sim/`: rng, world（レイアウト + 衝突）, cars, npcs, flyperson, sensors, sensing, sim
- `web/src/brain/`: types, manualBrain
- `web/src/render/`: assets, batch, townBuilder, stage, character, actors, cameraRig, compoundEye, debugOverlay, textures
- `web/src/ui/`: ui, perf, style.css
- `web/scripts/`: check-perf.mjs, sim-smoke.mjs
- `web/public/models/`: CC0 モデル（CREDITS.md、各 License.txt 付き、計 7.1 MB）

## 実行
- `cd web && npm run dev`（http://localhost:5173/flytown/）、`npm run build`、`npm run check:perf`（ビルド + preview、コンソールを読む）、`npm run check:sim`（ヘッドレスの数値確認）。
- URL 引数: `?flies=4&npcs=20&cars=15&seed=...`

## 実測（M1 Mac、Chrome 系ブラウザ、ウィンドウ 800x600 相当）
- 60 fps、draw 約 250〜300、三角形 14〜57 万（視点で変わる）。
- ヘッドレス sim: 1 tick 約 0.17 ms（ハエ人 4 + NPC 20 + 車 15）。
- 事故テスト: 動く車の 6 m 前に置くと 0.4 秒で転倒、5 秒後に復帰、事故 1 件。

## 既知の不足
- 体の腕・脚は剛体（ブロック体のため膝・肘なし）。groom は両腕を前に上げて左右に振る近似。
- 夜・時刻・天候なし。電撃殺虫器、ハエ取り紙、ハエたたきは未実装。
- 「置く」「注射器」は UI の仮ボタンのみ。
- 一般ビルは Kenney 既製品のため窓や色は固定。
- 複眼視点の六角は固定サイズのモザイクで、レイのセンサ配置とは別物（見た目のみ）。
- モバイル未実測。影は設定で切れる。シャドウ範囲は視点距離で 3 段階に切替。
- 目の高さの水平レイなので、低い物（ベンチ等）は仰角 -22 度の偶数番レイで拾う。
