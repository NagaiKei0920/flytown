# FLYTOWN（仮称）仕様書 Draft v0.1

2026-10-29。ハエの脳（FlyWire コネクトーム）を頭に入れた人型キャラクターが街を歩くブラウザゲーム。
ハエ脳の知見・回路抽出コードは `../flybot/` から流用する（`~/.claude/personal/notes/flybrain_knowledge.md`）。

## 1. 一言で
頭がハエの人（以下「ハエ人」）が街を歩く。プレイヤーは直接操作しない。街に匂い・熱・冷気・店・障害物を置き、
好きなハエ人にドーパミンを注射して、ハエの脳がどう反応し、何を覚えるかを眺めて遊ぶ。
行動はすべて、実際の配線を通った信号が下行ニューロン（DN）に届いた結果として決まる。台本で動かさない。

## 2. 先行事例（2026-10-29 調査）
| 名前 | 内容 | 本作との違い |
|---|---|---|
| [webgpu-fly](https://github.com/abgnydn/webgpu-fly)（MIT） | 全脳 13.9 万ニューロンの発火モデル + MANC + flybody をブラウザで。キーで DN を刺激してハエを目標まで走らせる | 体はハエ・街なし・神経修飾（ドーパミン）は明示的に対象外・WebGPU 必須・初回 300 MB・実時間より遅い |
| Eon Systems の全脳エミュレーション（2026） | コネクトーム + NeuroMechFly（MuJoCo）。歩く・身繕い・摂食 | 研究デモでゲームではない。行動の多くは学習済み制御器頼みとの批判あり |
| FlyWire 脳で DOOM / マリオ（2026, 報道） | ゲーム画面を感覚入力に、被弾時に PPL1 へ電流で強化 | ドーパミンは自動の報酬信号。プレイヤーが打つ道具ではない（記事本文は 403 で未読） |
| ChessFly / flyputer | 配線固定でチェス学習 / 小規模スパイキングで叩き避けゲーム | 抽象タスク |

結論: 「人型の体 × ハエ脳 × 街の感覚刺激 × プレイヤーが打つドーパミン（学習が残る）」の組み合わせは見つからなかった。
webgpu-fly が最も近く、比較対象として README に明記する。

## 3. 体験の中心
1. 街を眺める。ハエ人が 1〜6 人歩いている。人間の NPC と車も動いている。
2. ハエ人はゴミ捨て場に寄っていき、焼き鳥屋の煙を避け、車が迫ると羽を鳴らして地面すれすれを跳ぶ。
3. ハエ人をクリックし、注射器でドーパミンを打つ。打った瞬間に嗅いでいた匂いが「好き」または「嫌い」として残り、以後その店に寄る・避けるようになる。
4. 脳パネルで、どの感覚が光り、キノコ体のどこが変わり、どの DN が足を動かしたかを見られる。

## 4. 体（人型への見立て）
| ハエ | ハエ人 |
|---|---|
| 6 本脚の三脚歩容（左前・右中・左後 ⇄ 右前・左中・右後） | 三脚 A = 左足、三脚 B = 右足。位相と歩幅を DN 出力の前進速度から決める |
| 前脚 | 腕。身繕い（DNg11/DNg12 系）では両手をこすり合わせる・頭をなでる。摂食時は手を口へ |
| 羽ばたき（DNg02 系、巨大線維 DNp01 の離陸） | 背中の半透明の羽が振動し、体が地面から 20〜40 cm 浮いて滑るように進む。高度の上限は 40 cm（飛べない設定）。連続 3 秒まで |
| 口吻伸展（摂食） | 立ち止まって店先の食べ物に顔を近づける |
| 後退（MDN） | 後ろ歩き（ムーンウォーク） |
| 複眼・触角 | 頭部モデル。触角は匂いの濃い方へ傾く（見た目のみ） |

頭部は手作りの低ポリゴン（複眼・触角・口吻）。体は CC0 の人型（Quaternius 等）と歩行アニメを使う。

## 5. 脳
### 5.1 回路
- データ: FlyWire v783 結線表（flybot の `data/flywire/` に取得済み）と細胞注釈。
- 抽出: 次の感覚ニューロンから DN までの経路にあるニューロンを、シナプス数の閾値つきで集める。目標 2〜3 万ニューロン、結線 150 万本以下、配布サイズ 15 MB 以下（gzip）。
  flybot の CX + MB + LAL + DN（9,584）を含む。
- 視葉（約 7.7 万）は入れない。ゲーム側で計算した視覚特徴を視覚投射ニューロン（LPLC2・LC4 など）に直接入れる。
  同様に、匂い・温度・湿度・味は感覚ニューロン（ORN・温度・湿度・味覚細胞）に直接入れる。
- 注釈で確認済みの数（2026-10-29 実測）: 嗅覚 2,282、味覚 336（糖 32・苦味 42・水 30 ほか）、温度 29（暖 7・冷 9 ほか）、
  湿度 74、機械感覚 2,667（風・重力 484）、LPLC2 210、LC4 207、DNp01 2、DNa01 4、DNa02 2、MDN 4、DNp09 4、DNg02 25、PAM 307、PPL1 16。
  MN9（口吻）は名前で見つからず、M0 で探す。

### 5.2 計算
- 発火率モデル（flybot `brain/rate.py` と同じ式）。符号は伝達物質から（ACh・DA・5HT・OA は興奮、GABA・Glu は抑制）。
- 細胞タイプ単位のゲインで較正する（flybot M3b の方法）。配線は変えない。
- 50 Hz・サブステップ 2。ブラウザの Web Worker 内で CSR 疎行列の積を JS（Float32Array）で計算する。WebGPU は必須にしない。
- キノコ体の KC→MBON にドーパミン依存の 3 要素則（flybot `brain/plasticity.py`）。ハエ人ごとに重みを別に持つ。

### 5.3 出力（DN → 体）
| DN | 体の命令 |
|---|---|
| DNp09（P9） | 前進速度 |
| DNa01 / DNa02 の左右差 | 旋回 |
| MDN | 後退 |
| DNp01（巨大線維）+ DNg02 系 | 羽ばたき・低空の跳躍 |
| DNg11 / DNg12 系 | 身繕い |
| 口吻系（M0 で特定） | 摂食 |

写像は固定の線形（係数は文献と較正で決め、ゲーム中は変えない）。壁を通り抜けない・車に当たると倒れるのは物理であって判断ではない。
意思決定を補助するスクリプトは入れない（「障害物があれば曲がる」等を書かない）。

## 6. 街の刺激
各刺激は「街のオブジェクト → ゲームが計算する感覚量 → 入力する細胞」の 3 段で定義する。匂いは風で流れる簡易プルーム（格子上の拡散と移流）。

| 街のもの | 感覚 | 入力する細胞 | 期待するハエの反応（根拠） |
|---|---|---|---|
| ゴミ捨て場・熟れたバナナの果物屋 | 発酵臭（酢・エタノール） | ORN（DM1・DM4・DP1m 等） | 寄っていく（Semmelhack & Wang 2009） |
| カビ臭い路地 | ジオスミン | ORN（DA2） | 強く避ける（Stensmyr 2012） |
| 車の排気・人混み | CO2 | ORN（V） | 避ける（Suh 2004） |
| パン屋・ケーキ屋 | 糖（接触時）+ 甘い匂い | 糖 GRN + ORN | 近づいて止まり、食べる（Shiu 2024 の摂食回路） |
| コーヒー店 | 苦味（接触時） | 苦味 GRN | 食べずに離れる |
| 焼き鳥屋の煙・夏のアスファルト・室外機 | 暑い | 温度細胞（暖） | 避ける（Hamada 2008） |
| 冷凍倉庫・かき氷屋 | 寒い | 温度細胞（冷） | 避ける |
| 噴水・雨上がり | 湿度 | 湿度細胞（湿・乾） | 好む湿度に寄る（文献確認は M1） |
| 送風機・ビル風 | 風 | 機械感覚（wind_gravity） | 立ち止まる・向きを変える |
| 工事現場の粉じん | 体に付着 | 頭部の剛毛（head bristle） | 身繕いする |
| 自転車が並ぶ路地・看板 | 障害物の多さ | 視覚特徴 → LC 系 | 速度を落とす・向きを変える |
| 迫る車・振り下ろされるハエたたき（人間 NPC） | 接近（looming） | LPLC2・LC4 | 羽ばたいて跳ぶ（von Reyn 2014） |
| コンビニの照明・電撃殺虫器 | 光 | 視覚特徴（明るさ・左右差） | 寄っていく。殺虫器に触ると気絶して再出現 |
| ハエ取り紙 | 甘い匂い + 粘着 | ORN | 寄って捕まる（物理） |
| ほかのハエ人 | 集合フェロモン（cVA） | ORN（DA1・VA1v 等） | 集まる |

視覚特徴は、頭の位置から左右各 12 方向にレイを飛ばして求める（距離・接近速度・明るさ）。光学流の詳細計算はしない。

## 7. プレイヤーの道具
- 注射器（主役）: 対象のハエ人をクリック → 種類を選ぶ → 量（1〜3）を選ぶ → 打つ。
  - 「ご褒美」= PAM（キノコ体 γ・β' 区画）、「お仕置き」= PPL1、「全部」= 全 DAN。
  - 即時の効果（MBON 出力の変化による接近・回避）と、打った時点の匂いの記憶（KC→MBON の変化）の両方が起きる。
- 置く: 刺激オブジェクト（表 6）を道に置く・消す。風向きを変える。
- 時間: 一時停止・等倍・4 倍。
- 好み表示: 選んだハエ人の「匂いごとの好き嫌い」を -1〜+1 の数で表示する（各匂いを裏で入力したときの MBON 出力の差から計算）。
- 研究室モード（後回し）: 任意の細胞タイプを刺激する。

## 8. 遊び方
- 自由モード: 制限なし。
- お題モード: 1 つの数字で採点する。例
  - 「ハエ人を 3 分以内にパン屋へ入れる。使ったドーパミンの量が少ないほど高得点」（得点 = 達成時間 × 注射回数、小さいほど良い）
  - 「殺虫器の前を 5 往復させて、一度も触れさせない」
  - 「車道を渡らせる。事故 0 回で」
- 記録: ハエ人ごとに歩いた距離・食べた回数・事故回数・羽ばたき回数。

## 9. 画面
- 3D の街（俯瞰カメラ。ハエ人を選ぶと追従、複眼視点に切替可）。
- 右に脳パネル: 感覚 → キノコ体 / 側角 / 中心複合体 → DN の 4 列で、区分ごとの発火を光の強さで表示。注射の瞬間は該当 DAN が光る。
- 下にツールバー（注射器・置く・時間）。説明文は最小限。設定は設定タブに集約。
- 見た目: 明るい低ポリゴンの街、柔らかい影。羽は半透明で虹色の干渉色。

## 10. 技術
- Three.js（ビルドは Vite）、TypeScript。脳は Web Worker。GitHub Pages で配信。
- 回路の前処理は Python（flybot の `connectome/extract.py` を写して改造。元は触らない）。出力は CSR のバイナリ + メタ JSON。
- 街と人のアセットは CC0（Kenney City Kit、Quaternius）。第三者の非 CC0 アセットは使わない。
- 対象環境: MacBook Air（M1, 8 GB）の Chrome / Safari、教室 PC（Windows 11, i3 級）の Edge / Chrome。
- 性能目標: ハエ人 4 人で 60 fps 描画、脳は実時間以上（50 Hz）。初回読み込み 20 MB 以下。

## 11. 検証（数字で判定する）
- 刺激応答表（Python と ブラウザの両方）: 表 6 の各刺激を 1 つずつ与え、DN 出力の向きが期待と一致した割合。
  ゲート: 12 項目中 9 以上で一致。外れたものは README の「再現できなかった反応」に正直に載せる。
- 実装の一致: 同じ入力で Python とブラウザの発火率の最大誤差 1e-4 以下。
- 学習: 匂い A + ご褒美を 3 回 → A への接近率が注射前より 20 ポイント以上上がる（固定シード 20 回の平均）。
- 性能: 上記の対象環境で fps と脳の計算時間をログに出す。
- すべて CLI（`npm run verify`、`python -m tools.verify`）で再実行できる。
